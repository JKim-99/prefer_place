# 행정구역 경계 데이터

`sigungu.geojson`은 [mapcn-kr의 시군구 경계 데이터](https://github.com/DevMinGeonPark/mapcn-kr/blob/main/data/sgg.json)를 그대로 사용합니다. 원본은 통계청 SGIS의 경계 데이터로, [vuski/admdongkor](https://github.com/vuski/admdongkor)를 거쳐 mapcn-kr에서 시군구 단위로 병합하고 단순화했습니다. 라이선스: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). 원본 고지: [LICENSE-DATA](https://github.com/DevMinGeonPark/mapcn-kr/blob/main/LICENSE-DATA). 이 프로젝트는 일반구를 시 단위로 묶어 표시합니다. 원본은 2026-07-01 버전이며 전남광주통합특별시를 하나의 시·도로 제공합니다. 실제 서비스 적용 전 공식 행정구역 기준과 최신성 검증이 필요합니다.
